# ALA-002: Add An On-Demand Home Alarm Editor

# What

Add an alarm-setting interface that is summoned temporarily on the persistent
Home surface instead of occupying a channel or permanent dashboard region.

Before:

- Home shows the next armed alarm but deliberately provides no editor.
- The retired Alarm channel's keyboard editor is no longer part of the visible
  interface.

After:

- A deliberate request summons a focused alarm editor on Home.
- The editor uses the existing coordinator alarm actions and disappears after
  completion or cancellation, leaving the Home composition intact.

## Out Of Scope

- Reintroducing an Alarm channel or permanent settings screen.
- Multiple alarms, recurrence, labels, snooze, or a general widget framework.
- Changing endpoint sleep, RTC wake, alarm audio, or dismissal behavior.

# Heatmap

- **Medium — invocation:** The summon gesture and cancellation behavior need a
  deliberate product decision before implementation.
- **Medium — ringing state:** The editor must not compete with a due alarm's
  urgent dismissal flow.

# How to test

### Summon and dismiss

- **Start** - Open Home with the coordinator connected.
- **Action** - Invoke the accepted alarm-edit gesture, change the time, submit,
  then invoke it again and cancel.
- **Expected** - Editing appears only on demand, updates the existing alarm
  contract, and restores the unchanged Home surface after submit or cancel.
