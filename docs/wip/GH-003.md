# GH-003: Provision The Room Endpoint

# What

- Added one repository-owned provisioning command for the qualified Ubuntu
  iMac.
- Provisioned a dedicated LightDM, Openbox, and Chromium kiosk session at the
  panel's native resolution.
- Configured persistent Wi-Fi, local hostname discovery, wired fallback,
  unattended graphics and audio access, and the rear analog mixer route.
- Confirmed Wi-Fi-only kiosk and SSH recovery after reboot.

# Plan Diff

- The BCM4321 `14e4:4328` rejects `b43` as an unsupported dual-core device, so
  provisioning uses Ubuntu's `bcmwl-kernel-source` and explicitly prevents
  `ssb_hcd` from reclaiming the adapter during boot.
- `wpasupplicant` is installed explicitly because Netplan does not pull it into
  the no-recommends package set.
- Chromium's Snap confinement rejects the qualification `file://` URL, so the
  endpoint serves the static page on loopback with Python's standard HTTP
  server.
- Avahi and an unprivileged Xterm shortcut were added after the original Apple
  keyboard could not switch virtual terminals during recovery.
- Wait-online accepts either routable interface instead of failing when the
  intended Wi-Fi-only endpoint boots without Ethernet.
- At the user's direction, the placeholder receives one post-reboot resource
  spot check instead of a fifteen-minute soak or power measurement. Sustained
  measurement and physical Sonos playback move to GH-004's real client.

# Heatmap

Reference: `../project/HEATMAP.md`.

## Hot

### H1 - Keep Endpoint Provisioning Repository-Owned And Small

- Decision: Use one fail-fast shell entry point and committed static files.
- Where: `endpoint/imac/`.
- Why: One replaceable endpoint does not justify a configuration-management
  framework.
- Alternatives: Manual commands only; Ansible; a general multi-host installer.

### H2 - Use A Minimal Xorg Kiosk Session

- Decision: Use LightDM, Openbox, and Chromium over the qualified Xorg/Radeon
  path.
- Where: The endpoint packages and session files.
- Why: This avoids a desktop environment and does not make the old Radeon prove
  a new Wayland path before the first client exists.
- Alternatives: Cage and Wayland; a full desktop; a bare systemd X service.

### H3 - Keep Network Secrets On The Endpoint

- Decision: Prompt for Wi-Fi values and write them only to the root-readable
  Netplan file on the iMac.
- Where: `endpoint/imac/provision-host`.
- Why: Reproducible provisioning does not require publishing home-network
  credentials.
- Alternatives: Commit an encrypted secret; configure Wi-Fi outside the
  provisioning path.

# Notes

- `imac.local` is the stable SSH name; no network address is stored here.
- The proprietary `wl` driver is required because this BCM4321 revision is not
  usable through `b43`.
