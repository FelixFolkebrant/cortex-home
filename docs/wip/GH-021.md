# GH-021: Wake The Room

# What

- Added the coordinator-owned, one-shot alarm schedule and its normalized SSE
  snapshot.
- Added fixed arm, disarm, and dismiss actions; atomic alarm persistence; and
  Europe/Stockholm next-occurrence and restart-recovery behavior.
- Added the fifth fixed Alarm channel, its keyboard-only time editor, and the
  observed-arm `Ctrl`+`Enter` sleep interaction.

# Acceptance Criteria

- [x] The coordinator owns exactly one one-shot alarm with `disarmed`, `armed`,
  `ringing`, `missed`, or `failed` state and publishes a normalized alarm
  snapshot over the existing endpoint connection.
- [x] The selected `HH:MM` means the next occurrence in `Europe/Stockholm`; a
  time that has already passed schedules tomorrow rather than firing
  immediately.
- [x] The coordinator stores only the bounded alarm state and next UTC firing
  instant in its systemd-managed state directory using an atomic replacement.
- [x] A coordinator restart restores an armed future alarm. A due alarm up to
  15 minutes late rings immediately; an older due alarm becomes visibly
  `missed` and never surprises the room hours later.
- [x] Invalid, impossible, duplicate, stale, or out-of-range alarm requests
  fail without changing the current schedule.
- [x] A selected time that does not exist during the Europe/Stockholm spring
  gap is rejected visibly. During the repeated autumn hour, the alarm chooses
  the earliest matching instant that is still in the future.
- [x] `Ctrl`+`Alt`+`5` selects Alarm; keyboard editing is scoped to that view;
  plain Enter arms, Escape disarms, ringing Enter dismisses, and only an
  observed armed snapshot enables `Ctrl`+`Enter` sleep.
- [x] A due alarm selects Alarm, displays a live local clock, requests exactly
  `Warm low`, and leaves independent Hue, audio, and sleep-handoff failures
  visible without automatic retries or duplicate local players.
- [x] The endpoint installs and loops one root-owned fixed MP3, supports
  atomic replacement without a client rebuild, and exposes no audio picker,
  upload endpoint, or media catalog.
- [x] The exact-origin loopback bridge accepts only the observed bounded UTC
  epoch and invokes one root-owned `rtcwake --utc --mode mem` helper after
  stopping UxPlay and checking the local alarm file.
- [ ] A real iMac qualification confirms deep suspend, RTC wake, graphical and
  network recovery, live clock, `Warm low`, one alarm player, dismissal, and
  early-manual-wake behavior.

# Plan Diff

- The accepted plan was updated before implementation: plain Enter arms the

# Implementation Walkthrough

1. `coordinator/alarm.py` owns the fixed snapshot schema, local-time
   calculation, DST validation, due-or-missed recovery decision, and atomic
   JSON replacement.
2. `coordinator/cortex_home.py` adds `alarm.arm`, `alarm.disarm`, and
   `alarm.dismiss` to `/api/actions`, publishes `alarm.state` on endpoint
   connection and state changes, and schedules the one in-process due timer.
3. `coordinator/files/cortex-home.service` creates the service-owned
   `/var/lib/cortex-home` state directory. `./coordinator/install
   <server-ssh-host>` copies `alarm.py`, installs the unit, and restarts the
   coordinator.
4. `coordinator/client/src/AlarmChannel.jsx` mounts the editor only in the
   Alarm channel. `coordinator/client/src/alarm-editor.js` accepts exact
   non-repeating editing keys, plain Enter to arm, Escape to disarm, and
   `Ctrl`+`Enter` only for an observed armed snapshot. `Ctrl`+`Alt`+`5`
   selects the channel; selecting it from AirPlay first turns the receiver off.
   When the coordinator publishes `ringing`, that channel replaces the editor
   with a live Europe/Stockholm clock and its one-key dismissal instruction.
5. On the due timer, `coordinator/cortex_home.py` selects Alarm and invokes
   only the exact `Warm low` Hue scene through the existing observed scene
   activator. A scene failure stays visible on the ringing alarm and does not
   prevent dismissal or trigger an automatic retry.
6. `endpoint/imac/files/cortex-endpoint-alarm` owns one looping `mpg123`
   player for `/etc/cortex-endpoint/wake-alarm.mp3`. The origin-bound loopback
   bridge exposes only start and stop operations, and the Alarm view calls
   them only as its observed state enters or leaves `ringing`.
   `./endpoint/imac/provision-alarm-audio <local-mp3>` validates a bounded
   regular `.mp3` file and atomically replaces the endpoint-local file.
7. `Ctrl`+`Enter` sends the observed `firesAt` through `alarm.sleep`. The
   browser sends only its UTC epoch to the same origin-bound endpoint bridge;
   the bridge stops UxPlay, checks the alarm file, bounds the epoch again, and
   starts the root-owned `cortex-endpoint-rtc-suspend` helper. That helper can
   invoke only `/usr/sbin/rtcwake --utc --mode mem --time <epoch>`.
