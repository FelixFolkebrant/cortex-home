# GH-012: Publish Agent-Safe Room Context

# What

- Added a repository-owned pure coordinator context projection for the active
  Today or Music channel plus current lighting state.
- Added a locked `Coordinator.context()` method that returns a fresh reduced
  value without publishing it through HTTP or SSE.
- Documented the exact internal context contract and provider-field exclusions.

# Acceptance Criteria

- [x] One repository-owned pure function returns a new context value from exact
  active-channel, Today, Music, and lighting snapshots.
- [x] The top-level shape contains only `activeChannel`, `channel`, and
  `lighting`.
- [x] Today context contains availability, time zone, current conditions,
  forecast, and observation time without provider or cache fields.
- [x] Music context contains availability or playback state and, when present,
  item type, title, creators, collection, position, duration, and observation
  time without artwork URLs.
- [x] Lighting context contains only availability, ordered scene names, active
  scene names, and observation time.
- [x] Only the active channel's detail is included; inactive Today or Music
  content is absent.
- [x] Invalid or unavailable snapshots fail closed to small unavailable context
  rather than forwarding unexpected fields.
- [x] Mutating returned nested values cannot mutate coordinator-owned state.
- [x] Coordinator tests cover Today, Music, unavailable state, field reduction,
  invalid input, and copy isolation.
- [x] Existing coordinator, Hue, Today, endpoint, and frontend checks remain
  unchanged and pass.
- [x] The durable issue record documents the exact context contract and how a
  later adapter consumes it without exposing a new LAN endpoint.

# Implementation Walkthrough

- `coordinator/context.py` defines `build_room_context(active_channel, today,
  music, lighting)`. It validates the exact accepted snapshot keys, projects
  only the active channel into `channel`, and projects lighting into the
  sibling `lighting` object.
- The top-level context shape is always exactly:

  ```json
  {
    "activeChannel": "today",
    "channel": {},
    "lighting": {}
  }
  ```

- Today context uses `type: "today"`, `available`, `timeZone`, `current`,
  `forecast`, and `observedAt`. Current conditions keep only `condition` and
  `temperatureC`; forecast entries keep only `condition`, `date`, `highC`, and
  `lowC`.
- Music context uses `type: "music"`, `available`, `playbackState`, and
  `observedAt`. When an item is present, it also keeps `itemType`, `title`,
  `creators`, `collection`, `positionMs`, and `durationMs`.
- Lighting context uses `available`, `scenes`, `activeScenes`, and
  `observedAt`. Scene arrays are copied from the already normalized coordinator
  order.
- Invalid shapes, unknown fields, unsupported active channels, or inconsistent
  unavailable snapshots reduce to small unavailable context values instead of
  forwarding source fields.
- `coordinator/cortex_home.py` adds `Coordinator.context()`, which acquires the
  existing coordinator `RLock` and calls the pure projection using current
  `channel`, `today`, `playback`, and `lighting` snapshots. It does not retain
  the result or send it to any client.
- `coordinator/README.md` records the exact contract and states that a later
  adapter should call `Coordinator.context()` immediately before one local
  model request, then pass only that returned value to its supervised local
  process.
- Run the implementation locally with the existing coordinator entry point:

  ```sh
  python3 coordinator/cortex_home.py --host 127.0.0.1
  ```

- Run the repository checks with:

  ```sh
  python3 -m unittest discover -s coordinator/tests
  python3 -m unittest discover -s endpoint/imac/tests
  pnpm --dir coordinator/client check
  pnpm --dir coordinator/client test
  pnpm --dir coordinator/client build
  ```

# Heatmap

Reference: `../project/HEATMAP.md`.

## Hot

### H1 - Exact Internal Context Projection

- Decision: Build a single allow-listed context object from existing normalized
  coordinator snapshots instead of forwarding those snapshots wholesale.
- Where: `coordinator/context.py`
- Why: A future model adapter needs useful room context but must not inherit
  provider objects, credentials, artwork URLs, endpoint tokens, Hue resource
  IDs, or mutable coordinator dictionaries by accident.
- Alternatives: Forward all SSE snapshots; add a generic channel provider
  registry; let the future adapter inspect coordinator internals.

### H2 - No New Read Endpoint

- Decision: Keep the context behind `Coordinator.context()` with no HTTP route,
  SSE event, persistence, or model call.
- Where: `coordinator/cortex_home.py`
- Why: The next voice bridge can call the coordinator-owned method immediately
  before one local request without creating a LAN privacy or compatibility
  surface before it has a consumer.
- Alternatives: Add `/api/context`; publish a context SSE event; run the future
  agent as an external service that reads public coordinator state.
