# AIR-002: Keep AirPlay ready and recover connections

# What

Keep `Skärmen` available throughout the iMac kiosk session, without a browser
toggle, and recover a disconnected or stalled iPhone mirror automatically.

Before:

The user had to enter AirPlay and turn on a receiver switch. Changing to another
channel stopped UxPlay. The initial software-decoder/XVideo configuration did
not improve the observed iPhone rotation glitch.

After:

The endpoint session starts UxPlay before Chromium. It remains active across
all Cortex channels, while the AirPlay view only identifies `Skärmen`. The
browser and loopback bridge no longer expose receiver on/off controls. UxPlay
already rebuilds its receiver after a normal client teardown; `-reset 1` resets
an unresponsive connection after one three-second NTP timeout.

## Out Of Scope

- Replacing or upgrading UxPlay, or adding another casting protocol.
- A process, log, or window watcher to force restarts outside UxPlay's native
  connection lifecycle.
- PIN authentication, pairing persistence, or a remote receiver control API.

# Heatmap

- **Always-on discovery** — any device on the trusted home LAN can connect at
  any time while the kiosk is running, including while another Cortex channel
  is visible. This intentionally replaces the previous local activation step.
- **Recovery** — `-reset 1` prioritizes returning to a usable receiver after an
  interrupted connection over retaining a marginal network connection.

# How to test

### Always-ready receiver

- **Start** - Deploy with `./endpoint/imac/provision-media` and wait for the
  normal Today view.
- **Action** - On the iPhone, open Screen Mirroring before selecting the
  AirPlay channel. Then visit AirPlay with `Control`+`Option`+`4`.
- **Expected** - `Skärmen` is available in both cases. AirPlay contains the
  receiver name and no switch; choosing it opens the normal borderless,
  full-screen native mirror above the current channel.

### Disconnect and recovery

- **Start** - Mirror a moving iPhone screen to `Skärmen`.
- **Action** - Stop Screen Mirroring, wait five seconds, then reconnect. Repeat
  after interrupting the phone's network connection.
- **Expected** - A normal stop restores the browser and a second connection
  opens a fresh native mirror. An interrupted connection becomes available for
  reconnect after the three-second reset interval without an operator action.

### Rotation

- **Start** - Mirror a moving iPhone screen to `Skärmen`.
- **Action** - Rotate portrait → landscape → portrait several times.
- **Expected** - Record whether the original glitch remains. This change makes
  reconnect recovery automatic; it does not claim to repair the decoder issue.

# Notes

- UxPlay 1.68's source handles a normal client teardown by rebuilding its video
  renderer and relaunching the receiver. Its `-reset n` option resets a silent
  client after `3n` seconds; `-reset 1` is the shortest supported interval.
- The receiver is stopped only at kiosk-session cleanup. It remains running
  through Cortex channel changes and sleep preparation so a resumed kiosk does
  not require an additional receiver startup path.
- Automated checks passed: `bash -n` for the changed endpoint scripts,
  `python3 -m unittest endpoint/imac/tests/test_provisioning.py` (17 passed,
  3 skipped because this workspace lacks OpenBSD netcat), and the client test,
  check, and production build commands.
- This workspace could not authenticate to the iMac over SSH; the operator
  approved the completed always-ready receiver workflow for main integration.
