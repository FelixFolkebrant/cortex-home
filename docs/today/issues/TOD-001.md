# TOD-001: Compose Today And Music Channels

Previous identifier: `GH-010`.

## What

- Added coordinator-owned `channel.active` state with concrete `today` and
  `music` values; coordinator startup selects Today.
- Added the allow-listed `channel.select` action. It publishes the requested
  active-channel state before reporting completion and works while the endpoint
  is disconnected.
- Added a narrow yr.no Locationforecast 2.0 compact adapter for Linköping. It
  normalizes current weather and three local forecast days as `today.summary`.
- Added explicit full-screen Today and Music views in the existing React shell.
  Today shows local time, date, weather, forecast, and MET Norway attribution.
- Added fixed keyboard channel selection: `Ctrl`+`Alt`+`1` selects Today and
  `Ctrl`+`Alt`+`2` selects Music through the same coordinator action as curl.
- Changed channel feedback from a full-screen overlay to a compact upper-right
  toast so the selected view remains visible during its transition.
- Preserved Music playback, Warm state, connection feedback, and interaction
  overlays as independent client state across channel changes.

## Implementation Walkthrough

### 1. Publish Channel And Today State

`coordinator/cortex_home.py` owns the in-memory active channel and sends the
current `music.playback`, `channel.active`, `today.summary`, and
`room.lighting` snapshots to each server-sent-events connection. It starts with
`{"active":"today"}`.

Call one channel action from a local caller with a new request ID:

```sh
curl \
  --fail-with-body \
  --header 'Content-Type: application/json' \
  --data '{"requestId":"show-music-1","action":"channel.select","channel":"music"}' \
  http://<server-host>:8080/api/actions
```

Only `today` and `music` are accepted. An endpoint that is connected receives
`action.status` accepted, `channel.active`, then `action.status` completed; the
HTTP caller receives the completed result after the channel snapshot is
published. The action does not need an endpoint connection.

The full-screen browser is also a deliberate local caller: `Ctrl`+`Alt`+`1`
selects Today and `Ctrl`+`Alt`+`2` selects Music. The listener uses physical
`Digit1` and `Digit2` codes, so the mapping does not depend on the keyboard's
printed layout. It ignores held/repeated keys plus shifted or meta-modified
combinations, prevents the browser's default only for the two accepted
shortcuts, and displays the same accepted, completed, or failed interaction
feedback as another action caller.

### 2. Fetch And Cache Linköping Weather

`coordinator/today.py` is the only yr.no caller. It requests the compact
Locationforecast endpoint with fixed Linköping coordinates and the truthful
`CortexHome/1.0 github.com/FelixFolkebrant/cortex-home` User-Agent. The module
keeps provider response data and cache headers in
`/var/cache/cortex-home/locationforecast.json`, which the installer creates as
`root:cortex-home` mode `0770`; the systemd service runs in that group.

The adapter uses an unexpired cache without a network request. Once expired it
uses the stored `Last-Modified` value as `If-Modified-Since`; a 304 retains the
cached forecast with refreshed metadata. A 203 deprecated result, throttle,
bad payload, missing cache headers, or network failure produces the normalized
unavailable state. The browser never calls yr.no and receives no coordinates,
raw weather data, request headers, or cache metadata.

The client receives this shape, with `observedAt` added by the coordinator:

```json
{
  "status": "available",
  "timeZone": "Europe/Stockholm",
  "current": { "condition": "partly_cloudy", "temperatureC": 18 },
  "forecast": [
    { "date": "2026-07-26", "condition": "partly_cloudy", "highC": 22, "lowC": 18 }
  ]
}
```

### 3. Compose The Full-Screen Views

`coordinator/client/src/music.js` stores active channel and Today summary
independently from playback, lighting, connection, and interaction state.
`coordinator/client/src/App.jsx` switches only between explicit Today and Music
views. The shared connection notice and Warm status stay above either view.
Channel interaction uses a compact upper-right toast, so the view remains
visible while it changes; identification and Warm-scene interaction retain the
full-screen overlay because they need undivided room feedback.

Today uses the normalized `Europe/Stockholm` zone for its continuously updated
clock and date. It presents the current condition and temperature followed by
three quiet forecast cards. If the summary is unavailable, it shows only the
clock and a clear weather-unavailable message; it never presents an expired
forecast as current. Every state presents `Weather data: MET Norway · CC BY
4.0`.

### 4. Deploy And Recover

Deploy through the unchanged entry point:

```sh
./coordinator/install <server-ssh-host>
```

The installer rebuilds the React client, deploys `today.py`, creates the
service-writable cache directory, and restarts `cortex-home.service`. It needs
no weather credential, location prompt, or browser configuration.

To restart the coordinator without removing its weather cache:

```sh
ssh <server-ssh-host> 'sudo systemctl restart cortex-home.service'
```

When yr.no is reachable, Today should recover on the next adapter pass after a
restart. If it is temporarily unavailable or rate-limits the coordinator, the
Today view reports unavailable while Music, Warm, action handling, and
`/api/health` continue. Do not delete the cache for ordinary recovery.

## Problems Encountered

### 1. yr.no Provides A Time Series, Not Daily Cards

- Symptom: The compact response contains forecast instants and periods rather
  than a prebuilt three-day display model.
- Diagnosis: Current temperature belongs to an instant, while condition codes
  belong to the next forecast period.
- Resolution: Normalize an instant temperature and its nearest forecast symbol,
  then group forecast instants by `Europe/Stockholm` date for compact daily
  low, high, and midday-condition cards.
- Remaining caveat: The cards are a room-glance summary, not an hourly or
  meteorological detail view.

### 2. Existing SSE Tests Assumed Two Initial Snapshots

- Symptom: Adding channel and Today state caused tests to read a new snapshot
  as a later lighting or action event.
- Diagnosis: The initial endpoint contract now correctly contains four
  independent snapshots.
- Resolution: Tests consume and assert the complete named initial snapshot set
  before checking later action events.
- Remaining caveat: Any future endpoint snapshot must update that explicit test
  contract.

### 3. Later yr.no Entries Can Omit A Condition Summary

- Symptom: The deployed Today view showed weather unavailable even though the
  coordinator could reach yr.no and receive a valid compact response.
- Diagnosis: The initial normalizer required every entry in the complete
  nine-day response to carry a forecast-period symbol. Some later entries carry
  only instant measurements, outside the three-day room summary window.
- Resolution: Normalize only the first three local calendar days required by
  Today and add a regression fixture with a later instant-only entry.
- Remaining caveat: A missing symbol inside the visible three-day window still
  correctly makes the bounded summary unavailable rather than inventing a
  weather condition.
